The shortcut sheet, the command palette and layouts in the Print look. The shortcut sheet (`?`) is searchable by what a key does or by its keys, writes gestures as words, and has no "Got it" button. The command palette (Ctrl/⌘+K) puts the widget's own commands first with their keys, keeps the commands used last at the top, ranks what is typed, and has new commands: symbol search, compare, go to, reset the view, invert the scale, save the layout, the watchlist, alerts and objects panels and the shortcut sheet. Its rows show only keys that work (not while their switch is off, nor once `addHotkey` takes them). The strings `hotkeys.gotIt`, `common.navigate` and `common.select` are gone. The layouts dialog marks the layout open with a check and shows rename and delete on the row in hand; the menu says Save's keys.
