A new package: `@tradecanvas/mcp`, an MCP server for coding agents. `npx -y @tradecanvas/mcp` starts it; seven read-only tools look up the indicators (params and line keys), the drawing tools, the options of ChartWidget, Chart and ChartWidgetGrid, the feature switches and the style keys, from a catalog generated from the library's code. `validate_options` checks an options object and names the option likely meant.
